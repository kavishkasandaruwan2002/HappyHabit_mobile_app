🌱 HappyHabit – Habit Tracking Mobile Application

HappyHabit is a modern mobile application designed to help users build positive daily habits, improve consistency, and stay motivated through simple tracking and reminders.

🔗 Repository:
https://github.com/kavishkasandaruwan2002/HappyHabit_mobile_app

📌 Overview

In today’s busy lifestyle, maintaining good habits is challenging.
HappyHabit provides a simple, clean, and effective solution to create, track, and maintain daily habits while visually monitoring progress over time.

This project demonstrates mobile app development skills, UI/UX design principles, and state management using modern technologies.

✨ Key Features

✔ Create and manage daily habits
✔ Track habit completion status
✔ Reminder-based habit consistency
✔ Progress visualization
✔ Clean and intuitive user interface
✔ Lightweight and fast performance
